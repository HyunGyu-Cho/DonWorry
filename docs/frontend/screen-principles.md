# 화면 원칙과 공통 부품

2026-10-24 · Issue #22 · 기준 시안: 시연용 프로토타입 v4.2

돈워리 화면은 보안 직원 · 보안 관리자 · 가맹점 사장님이 쓴다. 개발자가 아닌 사람이 **ID나 코드를 몰라도 바로 이해하는 화면**이 목표다.
새 화면을 만들 때는 아래 원칙을 먼저 확인하고, 공통 부품(`src/components/explain/`)을 쓴다.

## 1. 원칙

| # | 원칙 | 나쁜 예 | 좋은 예 |
| --- | --- | --- | --- |
| 1 | 한 화면 = 하나의 질문 | 경보 · 세션 · 로그인 · 승인을 한 화면에 나란히 | "지금 판정할 사건이 무엇인가"만 묻는 사건 목록 |
| 2 | 결론을 먼저 | 근거 표부터 보여 주고 결론은 맨 아래 | 맨 위 결론 카드: "카드 도용 가능성이 있어 본인 확인이 필요합니다" |
| 3 | 숫자에 뜻을 붙인다 | `650000` | "65만 원 · 평소의 16배" |
| 4 | ID는 문장에 쓰지 않는다 | "AL-004 → 사건 CASE-101" | "박지원 계정 · 해외에서 비밀번호 성공 후 OTP 3회 실패" + 옆에 작은 회색 번호 |
| 5 | 값 옆에 평소와 비교 | `**** 1173` | "끝자리 1173 카드 · 이 고객이 처음 쓴 카드 ⚠ 처음 봄" |
| 6 | 원본 값은 펼치기 안에만 | 표에 `121.134.55.10 · DEV-1A42`가 그대로 | "국내 가정용 회선 (서울)" + [원본 값 펼치기] |
| 7 | 낯선 용어에는 풀이 | "HELD 상태입니다" | "<u>매입 보류</u>(툴팁: 카드 승인은 됐지만 아직 돈을 가져오지 않고 멈춰 둔 상태) 중입니다" |
| 8 | 표 머리글은 2~6글자 명사 (1-13) | "무엇을 · 누가 · 왜 · 언제 · 어디서" (질문형) | "요청 대상 · 요청자 · 사유 · 발생 시각 · 접속 위치" — 쉬운 풀이는 머리글이 아니라 화면 설명이나 칸 안 보조 글씨로 |

사람 말로 바꾸는 책임:

- 금액 · 시간 · 카드 끝자리 · 나라 이름 · 배수 → 화면(`src/utils/humanize.ts`)
- IP · 기기를 "사내망 · 박지원 업무 PC"처럼 부르는 설명 → **서버**가 `label`로 내려 준다 (`demo_fake_ips.label` 등). 화면은 설명이 없으면 "확인되지 않은 접속 위치"로만 바꾸고 IP 원문을 문장에 넣지 않는다

## 2. 공통 부품

| 부품 | 쓰는 곳 | 예 |
| --- | --- | --- |
| `ConclusionCard` | 보고서 · 사건 · 경보 맨 위 | 위험도 78 · "카드 도용 가능성이 있어 본인 확인이 필요합니다" · 권고 칩 |
| `FactLine` | 근거 · 결제 정보 목록 | `카드` · "끝자리 1173 카드 · 이 고객이 처음 쓴 카드" · ⚠ 처음 봄 |
| `CompareBadge` | 값 옆 | ✅ 평소와 같음 · ⚠ 처음 봄 · 🔴 차단 목록 |
| `TermTip` | 문장 속 낯선 용어 | `<TermTip term="HELD" />` → 점선 밑줄 "매입 보류" + 풀이 |
| `SmallId` | 제목 옆 · 표 끝 | 작은 회색 "결제 31" + 복사 |
| `RawDetails` | 화면 아래 | "원본 값 펼치기" → 접속 IP · 기기 ID · 카드 지문 |
| `NextActionButton` | 화면 끝, 하나만 | "판정하러 가기 →" + 한 줄 이유 |
| `ModeSwitch` | 헤더 | 튜토리얼 / 업무 모드 (튜토리얼 패널은 1-12) |

- 용어 풀이는 `src/config/glossary.ts` 한 곳에만 쓴다. 화면마다 풀이를 따로 적지 않는다
- 미리보기: `/dev/components`의 "09 · 화면 원칙 부품"

## 3. 새 화면 점검표

- [ ] 화면 제목이 질문 하나로 요약되는가
- [ ] 맨 위에 결론(또는 지금 할 일)이 있는가
- [ ] 제목 · 문장 · 표의 첫 열에 ID가 없는가 (필요하면 `SmallId`)
- [ ] 숫자마다 단위와 뜻(평소와 비교)이 있는가
- [ ] IP · 기기 ID · 카드 지문이 펼치기 밖에 없는가
- [ ] 처음 보는 사람이 모를 용어에 `TermTip`이 있는가
- [ ] 다음 할 일 버튼이 하나인가
- [ ] 표 머리글이 명사인가 ("걸린 Rule" 대신 "적중 Rule", "언제" 대신 "발생 시각")
